# FutureAICoders

This repository contains age-based curriculum plans for web coding and interactive media design.

## 1) Junior Kids (Ages 5-7)

### Learning Goals
- Understand what websites are and how pages are made.
- Use simple visual tools and basic HTML ideas.
- Build confidence through play, drawing, and storytelling.

### Web Coding Curriculum (6 Weeks)
1. **Week 1: Internet & Pages**
   - Activity: "Website scavenger hunt" (find menu, button, image).
   - Step-by-step:
     1. Show 2-3 kid-friendly websites.
     2. Ask children to point out titles, pictures, and buttons.
     3. Draw a "website map" on paper.
2. **Week 2: Meet HTML Blocks**
   - Activity: Build a page with heading + image using a block editor.
   - Step-by-step:
     1. Drag a title block and type their name.
     2. Add an image block.
     3. Preview and share with class.
3. **Week 3: Color & Style**
   - Activity: Change text color, size, and background.
   - Step-by-step:
     1. Pick two favorite colors.
     2. Apply colors to heading and page background.
     3. Discuss readable color pairs.
4. **Week 4: Buttons & Links**
   - Activity: Create a "Go to my favorite page" button.
   - Step-by-step:
     1. Add a button block.
     2. Paste a safe approved link.
     3. Test click behavior.
5. **Week 5: Mini Personal Page**
   - Activity: "About Me" webpage (name, favorite toy, picture).
   - Step-by-step:
     1. Add heading and short sentence.
     2. Add one image.
     3. Add one button link.
6. **Week 6: Showcase Day**
   - Activity: Pair presentation and positive feedback stars.
   - Step-by-step:
     1. Each child presents 1 minute.
     2. Peers share one thing they liked.
     3. Teacher gives completion badges.

### Interactive Media Design Curriculum (6 Weeks)
1. **Storyboarding Basics** - draw 3-scene stories (start, middle, end).
2. **Character Design** - create mascot with shapes and colors.
3. **Sound & Emotion** - match sounds to happy/sad/excited scenes.
4. **Simple Animation** - move object from left to right in slides/tool.
5. **Interactive Choice Story** - "If you click sun/moon, what happens?"
6. **Media Gallery Day** - display posters, animations, and story cards.

## 2) Senior Kids (Ages 7-10)

### Learning Goals
- Write beginner HTML/CSS with clear structure.
- Understand simple JavaScript interactions.
- Plan and produce interactive design projects with teamwork.

### Web Coding Curriculum (8 Weeks)
1. **Week 1: HTML Structure**
   - Build sections: header, paragraph, list, image.
2. **Week 2: Links & Navigation**
   - Build two connected pages (Home + Hobbies).
3. **Week 3: CSS Styling**
   - Fonts, color palette, spacing, borders.
4. **Week 4: Layout Practice**
   - Cards and simple grid/flex arrangement.
5. **Week 5: Intro JavaScript**
   - Button click changes message/color.
6. **Week 6: Forms for Feedback**
   - Name + favorite activity form design.
7. **Week 7: Mini Project Build**
   - "My Club Website" with 2-3 pages.
8. **Week 8: Testing & Demo**
   - Peer test checklist + class demo.

### Interactive Media Design Curriculum (8 Weeks)
1. **Design Thinking for Kids** - empathize, define, ideate, sketch.
2. **Visual Hierarchy** - title, subtitle, call-to-action placement.
3. **Color Psychology** - choose colors based on mood and message.
4. **Typography Basics** - pairing readable fonts.
5. **UI Components** - buttons, cards, menus, icons.
6. **Micro-interactions** - hover/click feedback in prototypes.
7. **Prototype Sprint** - team wireframe to clickable prototype.
8. **Critique & Improve** - structured feedback and revision cycle.

### Weekly Activity Pattern (Step-by-Step)
1. 10 min warm-up challenge.
2. 15 min concept mini-lesson.
3. 25 min guided build.
4. 15 min independent extension.
5. 10 min reflection + showcase.

## 3) Teenagers

### Learning Goals
- Build complete responsive websites with HTML, CSS, and JavaScript.
- Apply UX/UI, branding, and interaction principles.
- Publish project portfolios and present design rationale.

### Web Coding Curriculum (10 Weeks)
1. **Week 1: Web Foundations & Tooling**
   - File structure, semantic HTML, workflow setup.
2. **Week 2: Responsive CSS**
   - Flexbox, Grid, media queries.
3. **Week 3: Advanced Components**
   - Navbars, hero sections, cards, reusable patterns.
4. **Week 4: JavaScript Fundamentals**
   - Variables, functions, DOM selection.
5. **Week 5: Events & State**
   - Toggles, tabs, form validation.
6. **Week 6: Data-driven UI**
   - Fetching JSON and rendering lists/cards.
7. **Week 7: Accessibility & Performance**
   - Keyboard access, contrast, image optimization.
8. **Week 8: Version Control Practice**
   - Branching, commits, PR-style review.
9. **Week 9: Capstone Development**
   - Build personal or social-impact web project.
10. **Week 10: Deploy & Present**
   - Publish project and present technical decisions.

### Interactive Media Design Curriculum (10 Weeks)
1. **UX Research** - user personas and interview basics.
2. **Information Architecture** - content mapping and navigation flows.
3. **Wireframing** - low-fidelity desktop/mobile layouts.
4. **Visual Systems** - brand kit (color, type, components).
5. **Interaction Design** - transitions, feedback, motion principles.
6. **Prototype Testing** - task-based usability sessions.
7. **Iteration Cycle** - prioritize issues and redesign.
8. **Portfolio Storytelling** - case study writing with before/after.
9. **Collaborative Build Week** - design + coding integration.
10. **Exhibition Week** - final critique panel and public showcase.

### Capstone Guide (Step-by-Step)
1. Pick a real problem and target audience.
2. Define project goals and success criteria.
3. Sketch wireframes and content structure.
4. Build first coded prototype.
5. Collect user feedback from at least 3 testers.
6. Revise design and improve code quality.
7. Finalize accessibility, responsiveness, and content.
8. Publish and present outcomes with reflection.
